# TCM Images (中医图片库)

Traditional Chinese Medicine images repository for herbs, formulas, and medical illustrations.

## 结构

```
├── herbs/              # 中药材图片 (WebP)
├── formulas/           # 方剂图片
├── equipment/          # 医疗器械图片
├── techniques/         # 针灸/拔罐等技法
└── data/
    └── index.json      # 图片索引
```

## 使用

```typescript
const imageUrl = 'https://cdn.jsdelivr.net/gh/renhanxu/tcm-images@main/herbs/huangqi.webp'
```
